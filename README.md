# Manish Agarwal — .NET & Azure Portfolio

A responsive static portfolio website for presenting backend engineering services and planned demonstration projects.

## Before publishing

1. Open `index.html` in a browser and review every section.
2. Replace `YOUR_EMAIL@example.com` with a professional email address you want clients to use.
3. Keep demo statuses accurate. These are planned examples, not completed client projects.
4. Create a GitHub account if you do not have one yet: https://github.com/signup
5. Do not add employer code, client names, secrets, credentials, or confidential data.

## Preview locally

Double-click `index.html` to open it in a modern browser. No build tools or paid software are required.

## Publish for free with GitHub Pages

1. Create a GitHub account at https://github.com/signup.
2. Create a new public repository named `manish-agarwal-portfolio` (or another professional name).
3. Unzip this folder on your computer.
4. Upload `index.html` and `README.md` to the repository using **Add file → Upload files**, then commit the changes.
5. In the repository, open **Settings → Pages**.
6. Under the build/deployment source, choose **Deploy from a branch**.
7. Choose the `main` branch and `/ (root)` folder, then save.
8. Wait for GitHub Pages to publish. The site URL will appear in Settings → Pages.

## Suggested technical demo repositories

Build one project at a time:
- `insurance-claims-api` — fictional claims and status APIs using ASP.NET Core.
- `durable-order-workflow` — a simulated e-commerce workflow using Durable Functions.
- `azure-devops-dotnet-pipeline` — a .NET sample with YAML build and test stages.

For each project, add a README, architecture diagram, setup steps, tests, and an accurate statement of what is implemented. Do not claim production readiness unless you have tested and documented it.
